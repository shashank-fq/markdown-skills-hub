## C language and Python 

I have knowledge of C and basic Python. C is a low-level programming language known for its speed and control over system resources, making it ideal for developing operating systems, embedded systems, and performance-critical applications. Python, on the other hand, is a versatile, high-level language with simpler syntax, widely used for web development, data science, automation, and scripting. Combining C's efficiency with Python's flexibility allows me to tackle a range of projects, from system-level programming to application and web development
